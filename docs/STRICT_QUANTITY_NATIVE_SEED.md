# Closed strict quantity native seed

Experimental compiler target, not a hard realtime certification. The host uses the exact Forge strict i64 frontend at commit 38c261a38a0bdbc93f2971411879a9c90cb88d39 (tree eee62fe519564751f74f524889715df501b30a03). Supply its include directory when compiling `src/strict_quantity_seed.cpp`. No private source or token is required. The CLI reads a bounded .atto source on stdin and returns C++ for a freestanding no-argument i64 entry on stdout. Static proof failures return status 2 and no artifact. The target implements only closed refinement/quantity expressions; no dynamic input, scheduler, ownership runtime, general source compiler, or timing guarantee. The checked compile-time fold follows successful strict proof admission. Actual native object compilation, undefined-symbol checks, disassembly and linked execution are required for evidence; deadline, WCET and prefault remain NOT_CERTIFIED.
